## 2. 앱 개요
- 단일 페이지 웹앱(index.html + css/style.css + js/*). 빌드·외부 라이브러리·웹폰트 금지(오프라인 원칙). 한국어, 모바일 한 손.
- 목적: 상황(8개) × 피사체(2개) 고르면 현재 바디+렌즈 기준 Av 세팅(조리개·노출보정·ISO 자동 상한·최소 셔터)과 "다이얼 순서 3단계"를 10초 안에 보여줌.
- 핵심 UX: C1/C2 커스텀 모드 등록. C1=가만히 있는 사람(Av, ISO 자동 상한 6400, 최소 셔터 1/125, One-Shot, 1점 AF, 단사), C2=움직이는 아이(최소 셔터 1/500, AI Servo, 존 AF, 고속 연사). 현장에선 "모드 다이얼 C1 → 메인 다이얼 조리개 → 퀵 컨트롤 다이얼 노출보정"만.
- M 모드는 야경 배경 인물·실루엣만. M에선 ISO 수동, 노출보정 UI 숨김, 셔터·조리개·ISO 고정값 표시.
- 디자인: 토스(Toss) 스타일. 배경 #f2f4f6, 카드 흰색 20px 모서리 테두리·그림자 없음, 포인트 #3182f6, 글자 #191f28/#333d4b/#8b95a1, Pretendard 폴백 스택, 핵심 숫자 32px tabular-nums, 이모지 금지(인라인 SVG 선 아이콘만). 상단 탭은 pill 세그먼트, 렌즈 선택은 파란 채움 pill 버튼(토글 아님). word-break: keep-all.
- 앱 이름: 임시 "카메라 치트키"(localStorage 접두어 cck.). 후보: 다이얼(사용자가 "무슨 상관?"이라 반응 → 보류), 카메라 치트키(1픽), 세팅값, DSLR 설정. 부제 예: "DSLR 수동모드 설정 가이드". 키워드: 캐논,6D,DSLR,디에스엘알,수동모드,M모드,Av,조리개,셔터,ISO,노출보정,아웃포커싱,인물사진,아이사진,역광,출사,카메라입문.

## 3. 파일 구조와 원칙 (CLAUDE.md에 반영됨)
- docs/facts.md: 모든 숫자의 유일한 근거(6D2 스펙·메뉴 경로+매뉴얼 페이지·렌즈·EV 표·공식·자동 계산표·check.js용 json facts). 바디별 절(## EOS 6D Mark II, ## EOS 5D Mark IV …).
- js/data.js: CAMERAS(배열), LENSES, LIGHTS(EV), SUBJECTS, SCENES(8), STYLES(9), SETUP. 숫자는 facts.md에 근거 있는 것만. 추정 EV는 est:true, 못 찾은 메뉴는 page 생략→UI "미확인".
- js/exposure.js: compute(cameraId, sceneId, subjectId, lensId, override). EV100=log2(N²/t), t=N²·100/(S·2^EV), EC 반영 EV=EV−c. 핸드헬드 1/(환산초점거리), IS면 2^(isStops−2)배 여유, 상한 1/15. 1/3스톱 표준값 반올림. 플래그 isoCapped/tooDark/tooBright.
- js/dials.js: 다이얼 문구를 family별 템플릿으로(ff2dial / crop2dial / crop1dial / rf). family는 내부 분류, UI 노출 금지.
- js/app.js: 해시 라우팅(#home, #scene.id, #r.scene.subject, #style.id, #settings, 구분자 점). 마크업만.
- check.js: node check.js → data.js 전체를 facts.md와 대조, 계산표 재생성, CAMERAS×LENSES(호환)×SCENES×SUBJECTS 전 조합에서 tooDark/tooBright 있으면 실패.
- 원칙: Av 기본 / 시작값+현장 조정 규칙([조건, 조치] 쌍, 노출보정은 항상 "노출보정 ±x", ISO 상한 변경은 메뉴 경로 포함) / WB는 전 상황 AWB 분위기 우선(프리셋은 조정 규칙으로만) / 조리개는 lens.portraitAp + scene.apRule로 계산, 상황 데이터에 렌즈 id 직접 쓰지 않음 / 2탭 원칙 / 결과 화면 순서 ①다이얼 순서 ②숫자 ③AF ④현장 조정 ⑤왜 ⑥팁 / 바디 추가는 한 세션에 하나, 매뉴얼 원문 URL 필수, verified:true는 menu 11개 전부 page 있을 때만.

## 9. 검수에서 찾았던 오류 유형 (재발 방지용)
- HTP 켜면 최저 ISO 200 → 맑음 f/4가 1/4000 초과 (삭제함)
- M 모드에 노출보정 표시 (ISO 수동이면 의미 없음)
- 기본 조합에 tooDark 플래그 출고
- "ISO 한 단계 올리기. 12800 넘기면 노이즈" → 12800이 목표값처럼 읽힘
- adjust 두 규칙이 한 문장에 붙어 splitRule이 못 가름
- tips 데이터가 화면에 안 나옴
- 상황별 WB 프리셋이 C 모드에 저장 안 되는데 바꾸는 법 없음
- 레퍼런스 사진 역광 → 노출보정 +1 (상황이 아니라 스타일에 EC를 준 오류)
- 1024px 축소 후 EXIF 읽기 (순서 오류)
